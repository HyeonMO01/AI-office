# fizzylush v2 MVP Scope

## 핵심 포지셔닝

fizzylush는 "내 옷장을 기준으로 오늘 입을 코디를 추천해주는 AI 스타일링 앱"입니다.

첫 MVP에서는 쇼핑몰처럼 보이기보다, 사용자가 이미 가진 옷을 더 잘 입게 해주는 앱으로 보여야 합니다.

## MVP에 넣을 기능

### P0

- 이메일 회원가입/로그인
- 온보딩
- 옷장 사진 업로드
- 옷장 목록
- AI 옷 요약 태그
- AI 코디 추천
- 오늘의 코디
- 추천 기록
- 좋아요/별로 피드백

### P1

- 네이버 쇼핑 추천 카드
- 날씨 기반 추천
- 추천 결과 공유용 텍스트
- AI Office 문서 생성
- AI Office 토큰 관리

### P2

- 코디 캘린더
- 옷 터치 추천
- AI 코디 이미지 생성
- 가상 피팅
- 푸시 알림
- 결제/프리미엄

## MVP에서 뺄 것

- 정확한 가상 피팅 약속
- 과도한 고급 필터
- 복잡한 캘린더 UX
- 처음부터 글로벌 다국어
- 처음부터 결제 기능

## 성공 지표

- 첫 옷 업로드 완료율
- 첫 추천 생성 완료율
- 추천 좋아요 비율
- D1 재방문율
- D7 재방문율
- 주간 추천 사용 횟수
- 쇼핑 카드 클릭률
